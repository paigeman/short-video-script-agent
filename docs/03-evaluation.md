# 测试与评估

## 当前状态

项目处于初始化阶段。下表是计划验收内容，所有业务场景均未执行；不存在已通过的业务测试或真实模型效果结论。

| 场景       | 预期行为                           | 当前输入或待补材料                 | 状态   |
| ---------- | ---------------------------------- | ---------------------------------- | ------ |
| 正常生成   | 输出完整脚本、有效引用与检查结果   | `examples/normal.input.json`       | 未执行 |
| 缺关键信息 | 指出缺失字段并请求补充             | `examples/missing.input.json`      | 未执行 |
| 无素材     | 调整检索或请求资料，不编造事实     | 待添加输入                         | 未执行 |
| 工具失败   | 记录错误，由模型决定后续动作或结束 | `examples/tool-failure.input.json` | 未执行 |
| 超时长     | 模型压缩脚本后复检，或明确失败     | 待添加输入与实际超限记录           | 未执行 |
| 规则不通过 | 依据检查结果修正并复检             | 待添加输入与违规首稿记录           | 未执行 |
| 执行上限   | 停止循环并明确标记未完成           | 待添加受限运行配置                 | 未执行 |

## 证据约定

实际输出和 Trace 保存在 `examples/`，评估文档逐条链接对应文件。至少提供两条不同的模型执行路径，并记录模型标识、配置和运行模式。

测试报告须包含实际执行命令、结果与失败情况。工具单元测试、离线流程测试和真实模型运行分别陈述，不能互相替代。

## 计划观察的指标

- 必须验收场景的完成情况。
- 输出结构、来源 ID 和事实支持情况。
- 修改前后的预计时长与检查结果。
- 模型是否根据工具结果调整动作。
- 工具调用次数，以及可获取时的延迟和用量。

当前没有实测指标。真实口播时长、创意质量和业务收益不因通过结构或规则检查而自动得到证明。
