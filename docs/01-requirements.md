# 需求理解

本项目对应第 4 题「短视频脚本 Agent」，交付重点是有事实依据、符合时长限制的可编辑脚本。

## 用户

目标使用者是短视频创作者，需要把产品素材整理成面向特定受众和平台的脚本。使用时提供主题、受众、平台、目标时长和风格，再指定产品资料。

创作者需要查看每个镜头的文案与时间安排，确认产品表述有来源，并在资料不足或约束无法满足时得到明确说明。当前入口是本地 CLI，适合按 JSON 文件提交请求和查看结果。

## 目标

根据给定的创作要求和产品资料，生成包含标题、分镜、旁白或字幕的脚本。脚本预计总时长不得超过上限，产品事实必须能追溯到所引用的素材原文。

模型需要根据实际工具结果调整动作。检索无结果时可以改写查询或请求资料；时长、规则不通过时修改并重新检查，无法满足则明确返回未完成。输出同时保留风险、来源和检查记录，便于继续编辑与核对。

预期价值是减少从资料到脚本的整理工作，但本次没有测量整理效率、商业收益或发布效果。这些指标不作为已完成结论。

## 范围

| 纳入本次实现   | 边界                                             |
| -------------- | ------------------------------------------------ |
| 本地 CLI       | 接收 JSON 请求，返回 JSON 脚本、状态及 Trace     |
| 模型工具循环   | 真实模型选择动作，工具在本地执行，并设置次数上限 |
| 素材检索       | 只查询指定产品的合成资料，不做联网检索           |
| 时长与品牌检查 | 确定性估时、事实原文覆盖、数值依据和禁用表述检查 |
| 草稿修改       | 支持新建脚本和已有稿件诊断，修改后重新检查       |
| 编辑结果       | 六种镜头示意、旁白与字幕、各镜头起止时间         |
| 离线复现       | 明确标记的确定性模型替身，用于流程和边界测试     |

界面、线上部署、视频制作和真实发布未纳入本次实现。多 Agent、独立规划器与生产级运行时也不属于本次目标。自由文案改写、实际口播校准及独立人工创意评价仍有缺口，详见[最终记录](14-final-completion.md)。

## 输入、资料与输出

必填字段为 `topic`、`audience`、`platform`、`duration_seconds`、`style`、`product_id`。其中 `product_id` 用于隔离产品资料；时长是 1 至 300 的整数秒上限，这一范围是当前实现边界。可选 `initial_draft` 接收待修改的旧稿，旧稿仍须检索依据并重新检查。

资料由 `data/materials.json` 提供，包含素材 ID、产品 ID、事实原文和来源说明。`data/brand_rules.json` 定义获准过渡语、禁用表述及估时参数，全部为合成测试内容。

最终结果包含标题、分镜、旁白或字幕、预计总时长、素材来源 ID、风险与任务状态；额外提供镜头起止时间、检查回执和各版草稿。30 秒上限不要求正好填满 30 秒，也不表示生成过程只需 30 秒。

## 成功标准

| 验收场景       | 可核对的成功标准                                             |
| -------------- | ------------------------------------------------------------ |
| 正常生成       | 检索到素材，交付脚本结构完整；同一稿件的时长与规则检查均通过 |
| 缺关键信息     | 返回缺失字段和 `needs_input`，不猜测必填条件                 |
| 无素材         | 模型根据空结果改写查询、追问或停止，不添加没有依据的产品事实 |
| 工具失败       | 记录并回传实际错误，随后由模型重试、调整动作或明确停止       |
| 超时长         | 观察超限结果后修订并复检，或说明无法满足；不能提高原定上限   |
| 规则不通过     | 修改不合规文案并重新检查，或明确返回未完成                   |
| 改变时长或素材 | 输出与后续动作随约束变化，来源仍对应当前资料                 |
| 达到次数上限   | 返回 `incomplete`，保留已产生的记录，不伪造成功              |

最终脚本的素材 ID、分镜时长和检查结果必须对应同一 `draft_id`。仅有来源 ID 不足以证明文案有依据，产品表述还须得到所引事实原文支持。模型自主选择动作的要求由至少两条真实路径验证，不能只凭离线替身通过来判断。

预期与实际结果逐项列在[评估](03-evaluation.md)。总用时为 3h55min，3h 当时的完成程度以[冻结检查点](11-three-hour-checkpoint.md)为准。
