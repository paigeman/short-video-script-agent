# 需求

## 用户与目标

对应当前笔试第 4 题，帮助创作者生成有产品事实依据、满足时长上限的可编辑短视频脚本。未测量商业收益或创作效率提升。

## 输入、资料与输出

题目输入为主题、受众、平台、目标时长和风格；项目额外使用 `product_id` 选择产品素材，防止跨产品引用。所有文本字段必须非空，目标时长为 1–300 的整数秒。该范围是当前实现的配置边界，并非声称题目规定了这一范围。

本地合成资料包含稳定素材 ID、产品 ID、事实原文和来源描述。品牌规则定义事实引用、无依据量化效果、禁止表述，以及确定性估时参数。

输出包含标题、分镜、旁白、字幕、预计总时长、分镜素材 ID、来源事实、风险和业务状态。未完成时保留实际工具记录与原因，不输出伪装成功的 `script`。

## 当前范围

已实现 CLI、三个业务工具、模型驱动的调用循环、输出检查和离线验收。真实模型入口采用 Responses API，已对 DeepSeek `deepseek-flash` 完成实际验收，见 [截点后记录](12-post-checkpoint-acceptance.md)。

视频制作、发布、界面、线上部署、多 Agent 与独立规划器不在范围内。当前文案采用素材原文与获准过渡语组合，限制自由改写以获得可核验的事实边界。

## 成功标准

- 正常请求完成检索、估时和规则检查后交付脚本。
- 缺关键信息时明确请求补充，不能默认猜测字段。
- 无素材时模型可改写查询或请求补充，不编造产品事实。
- 工具失败时记录真实错误，由模型选择重试或停止。
- 超时长或规则不通过时修改草稿并复检，或明确返回未完成。
- 同一草稿的素材、分镜时长、检查记录相互对应，不能复用其他版本的检查结果。
- 达到次数上限时停止并保留已产生的记录。

实际离线与真实结果见 [评估](03-evaluation.md)。已提供八条真实模型路径，缺字段场景另外计入本地校验，不以模型替身替代真实证据。3 小时内的完成情况以 [冻结快照](11-three-hour-checkpoint.md) 为准。
