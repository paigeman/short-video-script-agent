# 需求

## 用户与目标

面向需要脚本初稿的内容创作者，生成有素材依据、满足目标时长的可编辑短视频脚本。当前没有测量商业收益或创作效率提升。

## 输入与输出

- 输入：主题、受众、平台、目标时长、风格，以及用于查找合成素材的产品 ID。
- 输出：标题、分镜、旁白或字幕、预计总时长、素材来源、风险和任务状态。
- 资料：本地合成素材与品牌规则。

## 范围

首版计划采用 CLI，接入一个真实模型和本地工具，完成带上限的决策循环。视频制作、发布、界面和线上部署暂不纳入范围。

当前已具备基础 Agent 运行时，输入的业务字段校验、短视频工具和上述业务能力仍待实现。

## 成功标准

正常输入可生成并检查脚本；信息不足时明确指出缺口；无素材时不编造事实；工具失败时明确记录结果；超时长时由模型修改并复检，无法满足或达到执行上限时说明未完成原因。

验收需要至少两条体现模型根据工具结果改变后续动作的真实路径。具体场景及证据见 [评估](03-evaluation.md)。
