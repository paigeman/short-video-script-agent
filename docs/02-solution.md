# 方案

## 当前实现

模型客户端、工具协议及执行器按需迁移自 [FadeDemo/AI-demo](https://github.com/FadeDemo/AI-demo)。连续调用流程已从原终端代码中提取，重组为 `AgentRunner`；它不依赖终端输入、历史裁剪、Tokenizer 或原项目的配置与模型档案。

| 模块                   | 当前职责                                    |
| ---------------------- | ------------------------------------------- |
| `src/llm/types.py`     | SDK 无关的消息、请求、响应、客户端协议      |
| `src/llm/responses.py` | 同步模型调用、协议转换、失败类别和资源关闭  |
| `src/tools/`           | 注册、Schema 校验、执行、错误回传和次数限制 |
| `src/agent/runner.py`  | 连续交互、输出修复、暂停与继续              |
| `src/validation.py`    | 严格 JSON 解析、Schema 校验和错误分类       |
| `src/agent/demo.py`    | 确定性替身与本地工具组成的离线验证入口      |

每次运行先调用模型。模型返回工具请求时，程序验证和执行工具，把实际结果交回模型；模型决定下一次调用或结束。一次响应中的全部调用先进入上下文，随后按序附加各自结果，并通过 `call_id` 对应。

默认上限为 3 个工具回传轮次、4 次模型请求、8 次实际工具执行。参数无效和未注册工具不消耗实际执行次数，但仍受模型请求与轮次上限约束。执行失败消耗一次执行预算。达到上限时保留已发生的 Trace，返回 `incomplete`。

通用控制由 `src/agent/control.py` 提供，结果与内存状态由 `src/agent/state.py` 表达。输出 Schema、补充信息、重试、超时与取消的接入方式见 [Agent 能力说明](08-runtime-capabilities.md)。

## 状态与记录

基础运行时的 `completed` 表示模型交互结束，并通过配置的输出 Schema 校验，不表示脚本满足业务验收。`needs_input` 等待用户回答，`cancelled` 表示取消后停止继续执行。`incomplete` 表示达到限制、模型未完整结束或没有有效最终文本；`model_error` 表示传输或协议失败。

Trace 记录模型请求次数、可见回应摘要、工具参数、结果摘要及结束原因。适配器回传所需的完整提供方输出仅保存在运行中的上下文，不写入 Trace。`usage` 未提供时保留空值，不推断为零。

模型请求关闭 SDK 自动重试，由运行器统一处理有限重试并记录次数。运行器限制累计活跃时间、上下文字节和工具输出大小，取消在操作边界生效。同步本地工具不能被强制中断，具体限制见能力说明。
