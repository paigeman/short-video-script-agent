# AI 使用与个人贡献

项目由人工决策、审查与 Codex 辅助实现共同完成。个人主要负责选题、范围和技术路线的决策，以及对实现方向、验收结果和交付材料的审查。本次代码迁移、业务实现、测试补充、问题定位和文档整理都有 Codex 的实际参与。

## AI 辅助内容

| 阶段             | Codex 执行的内容                                                      |
| ---------------- | --------------------------------------------------------------------- |
| 初始化与开发环境 | 参考示例组织目录，配置 Prettier、markdownlint-cli2、Ruff 与依赖锁文件 |
| 按需迁移         | 从 AI-demo 裁剪模型协议、工具执行和循环，调整导入与目录，补充测试     |
| 通用能力与业务   | 补充输出校验、恢复和运行限制，实现检索、估时、规则检查及 CLI          |

## 个人修改与审查

迁移来源为已有的学习项目 [AI-demo](https://github.com/FadeDemo/AI-demo)。本次迁移涉及的原项目代码，大部分是在此前的 AI 教学和讲解下手敲完成的学习成果。已有代码的学习与编写经历、本次裁剪迁移，以及本次新增实现分别记录。固定来源 commit 和文件映射见[迁移说明](07-migration.md)。

本次个人工作主要是以下决策和调整。

- 选择复用熟悉的代码，限定只迁移必要能力，允许重新组织目录；终端界面、Tokenizer、本地 Token 预算器和其他业务不迁入。
- 确定虚拟环境使用 uv，沿用已有项目的 lint 与格式化规范，并将来源写为远程仓库地址。
- 先完成离线验收，再选择 DeepSeek V4.1 Flash。真实密钥在本机自行填写，AI 不读取密钥文件。
- 对照试卷核查 ReAct 和审核要点，要求根据真实失败继续修复，补足已有稿件压缩和镜头表达的证据。
- 在 3h 时先冻结进度和未完成项，之后继续改进；最终登记 3h55min，并审查贡献边界与交付文档。

本次仓库中的具体代码修改主要由 Codex 执行。个人贡献集中在上述决策、配置和审查，没有将 Codex 实现的修复记为个人逐行手写，也没有将原项目的学习经历重复计作本次新增代码。
