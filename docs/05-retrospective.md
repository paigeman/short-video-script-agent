## 已解决的问题

最需要明确的边界是“模型结束”与“业务成功”的区别。最终结果不采用模型自行填写的检查状态，而以同一草稿的实际估时、事实和品牌检查记录为准。内容标识避免修改稿借用原稿的通过记录。

引用 ID 存在不等于支持文案。当前把产品表述限制为检索到的完整事实原文与获准过渡语，检查数值变造及各个文本字段。为避免 0.8 与 08 被误认为相同，事实比对保留内部标点。代价是不能接受任意自由改写，文案表达受到限制。

真实模型已验证工具故障后重试、无素材停止、超时长拒绝及无依据主张澄清。格式修复曾触发 HTTP 400，改用新用户回合并启用 JSON 输出后完成复验。失败记录与诊断保留，没有用成功重跑覆盖。
