# 复盘

## 3 小时截点

用户报告达到 3 小时时的已完成内容、失败与未完成事项，已单独冻结在 [3 小时进度快照](11-three-hour-checkpoint.md)。后续进度不覆盖该页及其证据；本页之后的更新属于截点后的工作。

## 当前阶段

在冻结 3 小时进度后，先修复真实输出格式链路并完成九场景复验，记录见 [截点后验收](12-post-checkpoint-acceptance.md)。随后补充既有稿件压缩、镜头类型和时间轴，十二场景复核符合预期、145 项离线测试通过，记录见 [审核补强](13-review-strengthening.md)。这些成果均不回填到截止快照。

## 已解决的问题

最需要明确的边界是“模型结束”与“业务成功”的区别。最终结果不采用模型自行填写的检查状态，而以同一草稿的实际估时、事实和品牌检查记录为准。内容标识避免修改稿借用原稿的通过记录。

引用 ID 存在不等于支持文案。当前把产品表述限制为检索到的完整事实原文与获准过渡语，检查数值变造及各个文本字段。为避免 0.8 与 08 被误认为相同，事实比对保留内部标点。代价是不能接受任意自由改写，文案表达受到限制。

真实模型已验证工具故障后重试、无素材停止、超时长拒绝及无依据主张澄清。格式修复曾触发 HTTP 400，改用新用户回合并启用 JSON 输出后完成复验。失败记录与诊断保留，没有用成功重跑覆盖。

短时长输入不保证模型首稿超限，不能将首稿直接通过当成修订能力证据。本轮将此前真实生成的 14.2 秒稿件用于新的 10 秒上限请求，观察实际超限后由模型压缩至 8.3 秒。速览初版虽符合事实规则，却重复讲解，因此进一步约束镜头数量和重复事实；教学使用特写被初版验收器误判，也说明自动判定必须核对原请求和输出。两项原始记录都保留。

## 后续工作

- 扩大真实素材和场景覆盖，检验单轮验收之外的稳定性；不把本轮通过率当作普遍效果。
- 人工评估主题、风格、受众及叙事质量，再决定是否引入语义改写验证。
- 录制或合成音频校准估时参数，比较估计与实际时长。
- 根据真实工作记录补充个人修改、学习过程与实际用时；不推测或代填时间。
- 如工具需要长时间运行，再增加工具自己的超时或进程隔离，避免扩大本次核心范围。
