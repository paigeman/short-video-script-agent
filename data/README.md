# 合成资料

本目录仅保存合成演示数据，不包含真实客户、业务或个人资料。

- `materials.json`：素材 ID、产品 ID、事实原文及来源说明。当前 P01 使用 M01，事实 ID 自动生成为 M01:F1、M01:F2。
- `brand_rules.json`：R01–R03 说明、获准过渡语、禁止表述与时长估算参数。修改可执行字段会改变检查结果，描述文字本身不会被解析成程序规则。

可通过 CLI 的 `--materials` 和 `--rules` 指定替代 JSON，并重新运行相同请求。素材 ID 需唯一、事实需非空，两类文件均须标记 `synthetic=true`。数据被加载为本次运行的副本，模型不能改写它们。

获准过渡语须由资料维护者确认不包含未经支持的产品事实。时长参数是演示估算假设，不代表对真实口播速度的测量。具体规则见 [业务说明](../docs/09-business-rules.md)。

补强阶段增加了“第一步”“回顾一下”等结构提示语，供教学和速览组织文案；没有增加产品能力或效果主张。每次真实验收输入快照保存当时实际使用的规则，旧记录仍按其原始规则解释。
